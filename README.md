# 🚀 Dilevery Pro - منصة التوصيل الذكية

منصة احترافية عالمية لإدارة التوصيل مع دعم متعدد اللغات (العربية، الفرنسية، الإنجليزية) ونظام خرائط ذكي مخصص للجزائر.

## ✨ الميزات الرئيسية

### 🔐 نظام المصادقة والأمان
- ✅ تسجيل المستخدمين مع تشفير كلمات المرور (bcrypt)
- ✅ نظام التحقق من البريد الإلكتروني (OTP) عبر Gmail
- ✅ جلسات آمنة باستخدام Express Session
- ✅ حماية ضد الاختراقات (CSRF, XSS)

### 🌍 تعدد اللغات (i18next)
- ✅ دعم كامل للعربية مع RTL
- ✅ دعم الفرنسية
- ✅ دعم الإنجليزية
- ✅ تبديل سلس بين اللغات مع حفظ التفضيلات

### 🗺️ نظام الخرائط الذكي
- ✅ إحداثيات افتراضية للجزائر (الجزائر العاصمة)
- ✅ تحديد نقطة الاستلام والتسليم بدقة
- ✅ Reverse Geocoding للحصول على العناوين
- ✅ علامات مخصصة للمواقع (Pickup: أخضر، Delivery: أحمر)

### 🌙 الوضع الليلي (Dark Mode)
- ✅ تبديل سلس بين الوضع الليلي والنهاري
- ✅ حفظ التفضيلات في Local Storage
- ✅ تصميم متناسق للوضعين

### 📊 لوحة التحكم الاحترافية
- ✅ إحصائيات شاملة (إجمالي التوصيلات، قيد الانتظار، مكتملة)
- ✅ عرض التوصيلات الأخيرة
- ✅ رسوم متحركة سلسة (Framer Motion)
- ✅ تصميم responsive لجميع الأجهزة

## 🛠️ التقنيات المستخدمة

### Frontend
- **React 18** - مكتبة واجهة المستخدم
- **TypeScript** - للكتابة الآمنة
- **Tailwind CSS** - للتصميم
- **i18next** - لتعدد اللغات
- **React Leaflet** - للخرائط
- **Framer Motion** - للرسوم المتحركة
- **Wouter** - للتوجيه
- **next-themes** - للوضع الليلي

### Backend
- **Express.js** - إطار عمل الخادم
- **Drizzle ORM** - للتعامل مع قاعدة البيانات
- **PostgreSQL** - قاعدة البيانات
- **Passport.js** - للمصادقة
- **Nodemailer** - لإرسال البريد الإلكتروني
- **bcryptjs** - لتشفير كلمات المرور

## 📦 التثبيت والإعداد

### المتطلبات الأساسية
- Node.js (v18 أو أحدث)
- PostgreSQL (v14 أو أحدث)
- حساب Gmail لإرسال البريد الإلكتروني

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone <repository-url>
cd dilevery
```

2. **تثبيت المكتبات**
```bash
npm install
```

3. **إعداد قاعدة البيانات**
```bash
# إنشاء قاعدة بيانات PostgreSQL
createdb dilevery_db

# نسخ ملف البيئة
cp .env.example .env
```

4. **تحديث ملف .env**
```env
DATABASE_URL=postgresql://user:password@localhost:5432/dilevery_db
SESSION_SECRET=your-super-secret-key
EMAIL_USER=your-email@gmail.com
EMAIL_PASSWORD=your-app-specific-password
```

5. **تشغيل Migrations**
```bash
npm run db:push
```

6. **تشغيل التطبيق**
```bash
# Terminal 1: تشغيل الخادم
npm run server

# Terminal 2: تشغيل Frontend
npm run dev
```

## 📧 إعداد Gmail للبريد الإلكتروني

1. انتقل إلى [Google Account Security](https://myaccount.google.com/security)
2. فعّل "2-Step Verification"
3. انتقل إلى "App Passwords"
4. أنشئ كلمة مرور للتطبيق
5. استخدم كلمة المرور في `.env` كـ `EMAIL_PASSWORD`
